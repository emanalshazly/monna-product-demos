# MONNA Product Demos

Public, evidence-led demonstrations derived from private product repositories.

- [PDF Form Filler Pro](https://emanalshazly.github.io/monna-product-demos/pdf-form-filler-pro/) — static architecture showcase; no PDF processing runtime.
- [Map AI Assistant](https://emanalshazly.github.io/monna-product-demos/map-ai-assistant/) — compiled interface with deterministic demo responses; no model calls.
- [Visual Strategy Canvas](https://emanalshazly.github.io/monna-product-demos/visual-strategy-canvas/) — compiled editable demo with deterministic sample generation; no model calls.
- [DoubleStep](https://emanalshazly.github.io/monna-product-demos/doublestep/) — static Android product and evidence showcase; no APK or gateway runtime.

The source repositories remain private. This repository contains only public-safe static artifacts and their provenance record.
